米議会が超党派AI法案「大米人工知能法」を公開——州のAI開発規制を3年間凍結、大手企業に連邦義務

共和・民主両党の6名の下院議員が6月6日、269ページに及ぶ「大米人工知能法（GAAIA）」草案を公表した。同法案は年間売上5億ドル超の大手AI企業を「大規模フロンティア開発者」と定義し、連邦レベルの義務を課す一方、州によるAIモデル開発規制を3年間停止させる条項を盛り込んでいる。AI利用・展開に関する州法は引き続き有効とされるが、モデルの構造・訓練に関する州規制は連邦法が優先される。公表直後から労働組合・消費者団体・民主党内委員会が相次いで反発し、法案の行方は不透明な状況だ。
