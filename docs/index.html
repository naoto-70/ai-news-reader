MoonshotのKimi K2.7 Codeが公開——推論トークン30%削減・1兆パラメータの長時間コーディング特化モデル

中国のAIスタートアップMoonshot AIは6月12日、1兆パラメータのMixture-of-ExpertsモデルKimi K2.7 Codeをオープンソースで公開した。32Bのアクティブパラメータを持ち、Hugging FaceにModified MITライセンスで公開されており商用利用も可能だ。前バージョン（K2.6）比で推論トークン数を約30%削減しながら、Kimi Code Bench v2で+21.8%、MLS Bench Liteで+31.5%の性能向上を達成している。256Kトークンのコンテキストウィンドウを備え、多ファイルのリファクタリングや長時間のデバッグといったエンドツーエンドのソフトウェアエンジニアリングタスクを主な用途としており、APIは入力$0.95・出力$4.00/100万トークンで提供される。

最先端AIがストループ心理テストで大失敗——複雑化で正答率が90%超から「ほぼゼロ」に急落

研究者らが最先端のAIモデルを対象に心理学の定番テスト「ストループ課題」を実施したところ、注意制御に重大な欠陥があることが判明した。短いリストでは90%以上の正答率を示したモデルが、リストが長くなるにつれてほぼ完全な失敗状態に陥った。ストループ課題とは「赤」という文字が青色で表示された際にインクの色を答えるような相反する情報を処理するテストで、AIはリストが長くなると「文字を読む」というデフォルト動作に戻ってしまう傾向が確認された。この結果はトランスフォーマーのアテンションメカニズムの根本的な制約を示しており、長期タスクで人間のような注意制御を維持することの難しさを浮き彫りにしている。
