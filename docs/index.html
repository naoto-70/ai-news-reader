Anthropic、評価額$900億超で$300億ドル調達完了 — OpenAI超え世界最高評価の非公開AIスタートアップへ

Anthropicは今週（5月26日の週）、DragoneerやSequoia Capital、Greenoaks Capital、Altimeter Capitalを共同主幹事として$300億ドル超の資金調達ラウンドを税前評価額$900億ドル超で完了し、3月時点でOpenAIが持つ$852億ドルの評価額を抜いて世界最高評価額の非公開AIスタートアップとなった。同社の年換算売上高は2024年1月の$8,700万ドルからわずか2年余りで$300億ドルへと急増しており、成長速度は異例の水準だ。今回の調達はAnthropicとして最後の非公開株式調達となる見込みで、2026年10月を目標としたIPOへの布石とされる。OpenAI・Google・Microsoftとの競争は資金力の観点でもいよいよ対等な構図となりつつある。

中国、Alibaba・DeepSeekなど民間AI企業の上位人材に海外渡航の事前承認義務を拡大

中国政府は5月26日、AlibabやDeepSeekなどの民間AI企業において「戦略的に重要」と判断した研究者・幹部に対し、海外渡航前に当局の事前承認を義務付ける規制を新たに適用した。従来は国有・政府系機関に限られていた渡航制限が初めて民間企業にまで拡大されたことで、AIの技術・人材の国外流出阻止に向けた国家管理の強化が一段と鮮明となった。この施策は2025年12月にDeepSeek幹部へ静かに適用されたことを皮切りに、2026年4月にはMetaによるManus AI買収（約$20億ドル）を政府がブロックするなど、管理の強化が連続している。AI覇権争いにおける米中の緊張が続く中、北京は人材と技術の両面で対外流出の封じ込めを本格化させている。

Microsoft Copilot Studio「コンピューター操作エージェント」が正式GA — Claude Sonnet 4.5搭載でWindows業務自動化が加速

MicrosoftはCopilot Studioの今年最大のアップデートとして、APIを持たないウェブサイトやデスクトップアプリのUIを直接操作する「コンピューター操作エージェント（CUA）」を全商用Powerプラットフォームリージョンで正式GA（一般提供）に移行した。GAビルドにはOpenAI CUAおよびClaude Sonnet 4.5がサポートモデルとして採用され、Azure Key Vault認証情報管理・Microsoft Purview監査ログ・人間承認ループ（HITL）などエンタープライズグレードの安全機能が同梱される。従来スクリプトや手作業に依存していたレガシーシステムのプロセス自動化を標準化されたエージェントで置き換えることができ、UIの変更にも自動適応する堅牢な仕組みが提供される。政府クラウドへの展開は2026年後半に段階的に開始予定で、Microsoft AIエージェント戦略の主軸製品として位置づけられている。

Gemini Interactions API v1betaが本日より新スキーマへ強制移行 — outputs廃止、6月8日に旧仕様完全削除

Googleは5月26日（現地時間）、Gemini APIのv1beta Interactions APIに破壊的変更を適用し、従来のoutputs配列をインタラクションの各ターンを構造化するsteps配列に置き換えた。あわせてresponse_mime_typeを廃止し、すべての出力形式制御を統合するpolymorphicなresponse_formatが新たに導入された。現時点では `Api-Revision: 2026-05-07` ヘッダーで旧スキーマへ一時的にオプトアウト可能だが、2026年6月8日以降は旧スキーマが完全に削除されるため、Geminiを組み込むアプリ開発者の対応が急務となっている。コンテンツ取得をoutputsからstepsへ切り替え、function_call・google_search_callの参照方法を変更し、次リクエストのinputフィールドにsteps配列を渡す形にヒストリー管理を修正する必要がある。

日本政府、高度AIモデルの悪用リスクへの対応強化 — 三大メガバンクへの「Claude Mythos」導入計画も発表

日本の総務省は、Anthropicの「Claude Mythos」をはじめとする高性能AIモデルの悪用リスクへの対策強化に向け、地方自治体・民間企業の代表者を集めた会議を開催した。Claude Mythosはシステムの脆弱性を発見する高度な能力を持つとされ、サイバー攻撃への転用リスクが指摘されており、官民連携による対応体制の整備を急いでいる。また、財務大臣は日本政府および三菱UFJフィナンシャル・グループ（MUFG）、三井住友フィナンシャルグループ（SMBC）、みずほフィナンシャルグループの三大メガバンクがClaude Mythosへのアクセスを取得する計画を明らかにした。AIの安全性と産業活用のバランスをどう図るかが、日本のAI政策における喫緊の課題として浮上している。
