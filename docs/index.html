AI透明性連合が立法アップデート——米国でAI透明性開示義務化・政府調達規制の法制化が加速

透明性連合（Transparency Coalition）が7月17日付けで公表したAI立法動向まとめによると、AIシステムの透明性開示を義務づける連邦・州レベルの法案が複数の議会委員会を通過し、法制化への動きが加速している。特に連邦政府機関が調達するAIシステムへの監査義務や文書化要件が強化される見通しで、2026年中の成立が現実味を帯びてきた。AI生成コンテンツへのウォーターマーク義務化とディープフェイク対策に関する法案も優先審議対象となり、AI責任の法的枠組み整備が進んでいる。中国主導のAIガバナンス議論が国際的に注目を集める中、米国が自国の規制基盤を固める動きとして国際的なAIルール形成にも大きな影響を与えそうだ。
