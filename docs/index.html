GoogleがGemini 3.6 Flash・3.5 Flash-Lite・3.5 Flash Cyberを同時リリース——出力コスト削減と知識カットオフ2026年3月への更新

Googleは2026年7月21日、3種類の新Geminiモデルを発表した。主力モデル「Gemini 3.6 Flash」は3.5 Flashと比べてアウトプットトークンを17%削減し、出力料金も100万トークンあたり9.00ドルから7.50ドルに値下げ、知識カットオフは2025年1月から2026年3月に大幅前進した。DeepSWEコーディングベンチマークでは49%（3.5 Flashの37%から大幅向上）、OSWorld-VerifiedのPC操作能力は83.0%（78.4%から向上）を達成した。さらにGoogleは同社史上最大規模の事前学習が進行中の次世代フラッグシップ「Gemini 4」の準備状況についても言及しており、2026年後半の大型リリースへの期待が高まっている。

NVIDIAがVera CPUの全仕様とSPEC CPU 2026ベンチマークを公開——88 Olympusコア・1.2 TB/sでAMD EPYC比3%優位

NVIDIAは自社初のカスタムCPUアーキテクチャ「Vera CPU」のホワイトペーパーとSPEC CPU 2026ベンチマーク結果を公開した。Veraは88基のOlympusコア・176スレッドと164MB統合L3キャッシュを1枚のモノリシックダイに集積し、LPDDR5Xメモリで1.2 TB/sの帯域幅を実現する。SPEC CPU 2026の整数SPECrateではデュアルソケット構成でスコア925を記録し、AMD EPYC 9755（898）を約3%上回った。エージェントAI処理における最大シングルスレッド性能を追求した独自設計で、AMD・IntelとのCPU市場での本格競合に向けた詳細設計が明らかになった。

英AISI報告：オープンウェイトモデルがフロンティアモデルのサイバー攻撃能力に急速接近——格差はわずか4〜10ヶ月に縮小

英国AI安全機関（AISI）の最新評価報告書によると、自由にダウンロード可能なオープンウェイトモデルと最先端クローズドモデルの攻撃的サイバー能力の格差は、2025年を通じた6〜10ヶ月から4〜10ヶ月へと縮小した。GLM-5.2やDeepSeek V4-Proは完全自律的なサイバー攻撃シミュレーションを実行でき、最新オープンモデルは3〜7ヶ月前のフロンティアクローズドモデルと同等の能力を持つと評価された。ネットワーク接続インフラを運用する組織が直面するAI活用サイバー攻撃リスクの窓は「有限・測定可能・縮小傾向」にあると報告は結論付けており、準備期間の短縮が重大な懸念事項として浮上している。AISIは英国NCSCとの連携によるフロンティアAI防衛活用の試験プログラムも並行実施しており、攻防両面でのAI活用競争が加速している。
