Model Release 2026-07-05

Anthropic、「Claude Sonnet 5」を正式公開——Opus 4.8に迫る性能を低コストで提供、エージェント自動化の新基準に

Anthropicは6月30日、最新中堅モデル「Claude Sonnet 5」を正式公開し、Claude.aiの無料・Proプランのデフォルトモデルに採用した。入力100万トークンあたり2ドル・出力10ドル（8月31日まで）という価格設定ながら旗艦モデルOpus 4.8に近い性能を発揮し、コーディング・ツール使用・推論の各タスクで前モデルのSonnet 4.6を大幅に上回る。計画立案・ブラウザ操作・ターミナル実行といったエージェント動作を低コストで実現する「最もエージェント指向なSonnet」として設計されており、意図的な悪用への協力や欺きといった「望ましくない動作」の発生率も顕著に低下した。AIエージェント自動化が企業の標準インフラへと移行する中、Anthropicがコスト競争力と性能の両立を実証した節目のリリースとなった。

Research 2026-07-05

Anthropic、研究者向けAIワークベンチ「Claude Science」を公開——ゲノム・構造生物学・ケモインフォマティクスの60以上のツールを統合、自社創薬プログラムも始動

Anthropicは6月30日、科学研究者向けの専用AIワークベンチ「Claude Science」をPro・Max・Team・Enterpriseユーザー向けにベータ公開した。ゲノミクス・プロテオミクス・構造生物学・ケモインフォマティクスなど60以上の科学データベースとツールを統合した統一プラットフォームで、コードを書かずに複雑な研究ワークフローを実行できる。同時に希少疾患・顧みられない疾患を対象とした独自の前臨床創薬プログラムの開始を発表し、OpenAIやGoogleとの競合が激化するAI創薬市場に本格参入した。最大50件のプロジェクトに最大3万ドル相当のAPIクレジットを付与する「AI for Science」支援プログラムへの応募は7月15日まで受け付けている。

Infrastructure 2026-07-05

日本政府、ソフトバンク・ソニー・NEC・ホンダの国産AI基盤コンソーシアム「Noetra」に最大1兆円投資——2040年までに18業種で1000万台のAIロボット展開へ

日本政府は7月1日、ソフトバンク・ソニー・NEC・ホンダの4社が設立した国産AI基盤モデル開発コンソーシアム「Noetra」に対し、NEDOを通じて5年間で最大1兆円（約63億ドル）を投資すると発表した。Noetraは産業技術総合研究所（AIST）と連携し、フィジカルAIに特化した兆規模パラメータの基盤モデルを2026年度内に初版リリースする計画で、製造業データを活用した年次改良を重ねていく方針だ。参加企業は将来的に自動車・電子・金融・物流など44社まで拡大予定となっている。改訂版AIロボット戦略では飲食・食品製造・医療など18業種へのAI搭載ロボット1000万台の2040年導入目標も掲げており、米中AI覇権に対抗する国産AIエコシステムの構築が急加速している。

Policy 2026-07-05

OpenAI、米政府に株式の5%（約4兆6000億円相当）を譲渡する構想を非公式提案——AI収益を国民に分配するアラスカ基金モデルを採用

フィナンシャル・タイムズなどの報道によると、OpenAIは7月2日、米政府の政治的圧力を和らげる目的で会社株式の5%を政府保有の投資ビークルに譲渡する構想を非公式に提案していることが明らかになった。現在の企業評価額8520億ドルを基準にすると5%の価値は約426億ドル（約6兆2000億円）に相当し、AI開発の利益を広く国民に還元するアラスカ州永久基金をモデルにしている。ただし検討は「概念的な段階」にとどまり、Anthropic・Google・Metaなど他の主要開発者が同様の枠組みに参加するかは不明で、制度化には議会の立法が必要になる可能性もある。同時期にホワイトハウスはOpenAI・Google・AnthropicとフロンティアAIモデルの任意的リリース基準策定についても交渉を進めており、AIを巡る政府と民間の関係が新たな局面を迎えている。

Open Weights 2026-07-05

ポルトガル政府、欧州初の国産オープンLLM「Amália」をわずか700万ユーロで公開——Apache 2.0ライセンスでHugging Faceに提供

ポルトガル政府は7月1日、欧州ポルトガル語に特化した初のオープン大規模言語モデル「Amália」をApache 2.0ライセンスでHugging Faceに公開した。開発費はわずか700万ユーロ（約11億円）で、数十億ユーロを調達したフランスのMistral AIなど欧州の競合と比較して破格のコスト効率を実現している。モデルは国のデジタル主権確立と行政サービス近代化を目的に構築され、政府機関・学術研究機関・国内スタートアップが自由に利用・改変できる。欧州各国が「AIの米中依存からの脱却」を掲げる中、小規模予算で独自モデルを実用化したポルトガルの事例はEU内の他国政府にとっても重要な先例となっている。
