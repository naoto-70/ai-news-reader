米国政府がAnthropicのFable 5・Mythos 5への外国人アクセスを即日禁止——ジェイルブレーク報告が引き金に

米商務省は6月12日、国家安全保障を理由にAnthropicの最上位モデルFable 5・Mythos 5への全外国人アクセスを即日停止する輸出規制命令を発令した。別の企業がMythosのジェイルブレークに成功したと主張したことが契機で、政府は実質的なアクセス遮断をAnthropicに同日命じた。Anthropicは「指摘された手法は限定的なもので全保護を無効化するものではない」と反論しつつも、リアルタイムで外国人ユーザーを分別する技術的手段がないとして、世界全ユーザー向けのFable 5・Mythos 5サービスを停止せざるを得なかった。この事態は企業AI戦略における「ハードウェア主権」——クラウド依存からの脱却——の議論を急速に加熱させている。

日本が外科医不足をAIで解決へ——スタートアップDireavaが画像解析による手術指示AIを政府支援で開発

日本では2043年までに消化器外科医数が現在の約1万6千人から半減すると予測されており、政府が外科医支援AIの開発を急いでいる。東京のスタートアップDireavaは生成AIを活用して臓器・血管の画像を解析し、手術手順を段階的にテキスト指示として生成するシステムを政府支援のもとで開発中だ。医療専門家による評価では85〜90%の正確率が確認されており、初期段階での実用性が認められている。ただし、このタイプの医療AIに特化した安全・評価基準がまだ日本国内に存在しないため、臨床での広範な採用には規制整備という大きなハードルが残っている。
