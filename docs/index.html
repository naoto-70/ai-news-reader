日本人の約6割が夏休みの旅行計画に生成AIを活用——観光地情報から旅程作成まで急速に浸透

日本で今夏の旅行を計画している人の61.2%が生成AIを活用していることが最新調査で明らかになった。国内・海外旅行を予定する回答者の過半数が、旅程の作成や観光地の食事・交通手段に関する情報収集にAIを利用している。旅行業界では、AIが特定の観光地への集中を助長するオーバーツーリズムの懸念が浮上する一方、個人化された旅程提案サービスへの需要が急増しており、AI旅行アシスタントの市場競争が本格化している。消費者向けAIが、旅行計画という日常的な意思決定プロセスに深く浸透しつつあることを示す象徴的なデータとして注目されている。

中国、先進AIモデルへの海外アクセス制限を検討——商務省がAlibaba・ByteDance・Z.aiと協議

中国商務省がAlibaba・ByteDance・Z.aiの幹部と会合を持ち、国内の最先端AIモデルへの海外からのAPIアクセスを制限する措置を検討していることがロイターの報道で明らかになった。背景には、中国製モデルの米国企業向けAPIトラフィックが1年前の約4.5%から現在は30〜46%にまで急拡大したことがある。議論ではクローズドとオープンソースの両モデルが対象となっており、先端AI技術の流出をロシア安全保障法上の違反として扱う可能性も示唆されている。米国企業の中にはコスト削減を目的にAnthropicなどからDeepSeekへ乗り換えた例もあり、制限が実施された場合の影響は広範に及ぶ可能性がある。

日本の総務省、人手不足の地方自治体にAIエージェント導入を検討——全自治体の74%がすでにAIを活用

総務省は、深刻な人手不足に直面する地方自治体の業務を自律的に処理するAIエージェントの導入検討を開始した。2025年10月時点で全国自治体の74%が何らかの形でAIを活用しており、今後はタスクを自律実行できるエージェント型AIへの移行が議題に上がっている。少子高齢化による行政サービスの担い手不足が深刻化する中、AIエージェントが窓口対応・文書処理・スケジュール管理などの業務を代替することで、住民サービスの質維持を図る狙いがある。政府は7月7日に設置を決定したAI変革推進協議会とも連携し、地方自治体へのAI展開を加速する方針だ。

OpenAI、フルデュプレックス音声AI「GPT-Live」を全ユーザーに展開——ターン制を廃し同時並行の自然会話を実現

OpenAIは7月8日、フルデュプレックスアーキテクチャを採用した新世代音声AIモデル「GPT-Live」をすべてのChatGPTユーザーへ展開した。従来のターン制モデルとは異なり、GPT-Liveは聴取・発話・推論を同時並行で実行し、人間同士の会話に近い自然な割り込みや相槌が可能になった。GPT-Live-1とGPT-Live-1 miniの2バリアントが提供され、無料プランにはminiが、有料プランにはGPT-Live-1がデフォルト音声体験として割り当てられる。バックグラウンドでGPT-5.5が稼働し、ウェブ検索や複雑な推論が必要な場合はフロンティアモデルへのタスク委譲も自動で行われる。
