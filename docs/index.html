Apple、EU向け新Siri AI提供を無期限延期——DMAをめぐる欧州委員会との対立が膠着状態に

AppleはWWDC 2026（6月8日）で発表した新Siri AIについて、デジタル市場法（DMA）をめぐる欧州委員会との対立により、EUではiOS 27・iPadOS 27向けの提供を無期限で延期すると発表した。新SiriはGoogleのGeminiモデルを基盤としており、欧州委員会はAppleが競合アシスタントより有利な立場に立つことをDMAが禁じる競争上の優位と見なしている。Appleは対抗策として「Trusted System Agent」を18ヶ月かけて段階導入する提案を行ったが、欧州委員会は6月9日に「SiriのEU非提供はAppleの自発的なビジネス判断だ」と公式に声明を出した。EU域内4億5,000万人以上のiPhone・iPadユーザーが影響を受ける一方、macOS 27・visionOS 27・watchOS 27では引き続き利用可能となる見通しだ。
