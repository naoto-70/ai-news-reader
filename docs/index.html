深圳大学、光AIで医療診断をGPU比246倍効率化——肝臓CTを0.8ミリ秒で処理する光ニューラルネット

深圳大学のHan Zhang教授らのチームが、黒リン（ブラックフォスファラス）ベースの可変変調器を用いた全ファイバー型フォトニクスAIプラットフォームを開発し、網膜剥離と肝臓がんの診断において専門医レベルの精度を達成しながら、従来のGPUと比べて246倍のエネルギー効率を実現したと発表した。肝臓CTスキャンの処理時間は電子プロセッサの85ミリ秒に対し0.8ミリ秒と大幅に短縮しており、ニューラルネット演算をすべて光の領域で完結させる「コヒーレント光コンピューティング」の臨床応用可能性を示す画期的な成果だ。従来の「電子から光子へ」の置き換えが主に理論にとどまっていた光ニューラルネットワークを、実際に展開可能な臨床診断プラットフォームとして初めて実証した点が評価されている。AI医療診断のエネルギー消費削減と高速化を両立するグリーンAIの新たな方向性として、世界の研究機関が注目している。
