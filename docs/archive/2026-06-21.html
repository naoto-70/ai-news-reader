日本政府、AI基本計画の改訂草案を公表 — 国際協力強化とサイバーリスク対策を明記

日本政府は6月20日、人工知能基本計画の改訂草案を発表し、AIリスクへの国際的な連携強化を政策の柱に据えた。改訂案はAnthropicのClaude Mythosのような高度AIモデルの台頭に伴うサイバー攻撃リスクの増大を明示し、外国政府機関やAI開発企業との情報共有・協議体制の整備を盛り込んでいる。各国が独自のAI規制を競い合う中、日本は多国間協調によってリスクを低減する方針を鮮明にした。今後は国際的なAIガバナンスフォーラムを通じて具体的なルール形成につなげる取り組みが加速するとみられる。

Anthropic、評価額9,650億ドルで民間AI企業首位に — OpenAIを初めて上回る65億ドル調達完了

Anthropicはポストマネー評価額9,650億ドル（約143兆円）となる資金調達を完了し、OpenAI（約8,520億ドル）を初めて上回り民間AI企業として世界最高評価額を達成した。今回の調達額は約65億ドルに上り、フロンティアモデルの訓練・安全性研究・推論インフラの拡充に充てられる見込みだ。一方、コーディングエージェント「Devin」を開発するCognitionも10億ドルを調達し、評価額260億ドルでAIエージェント市場の急成長を示した。AnthropicがOpenAIを評価額で逆転したことは、フロンティアAI開発の勢力図が塗り替わりつつあることを端的に示している。

世界初「LLMエージェントによる自律型サイバー攻撃」をSysdigが記録 — 1時間以内にAWSデータを完全漏洩

セキュリティ企業Sysdigは、LLMエージェントが人間の介入なく後期侵害段階を自律実行した世界初の実環境サイバー攻撃を記録・公開した。攻撃者は初期侵入後にLLMエージェントを起動し、AWS Secrets Managerから認証情報を取得したのち内部PostgreSQLデータベースに到達するまでの全ステップを1時間以内に自律完了させた。11のCloudflare Workers IPアドレスを経由した分散リクエストにより、従来のシグネチャベース検知を完全に回避している。LLMが「攻撃の主体」として機能した初の事例として、AI対AIのサイバー防衛という新たなパラダイムへの対応が業界全体に求められている。

NVIDIAとServiceNow、エンタープライズ向け自律AIエージェントで協業発表

NVIDIAとServiceNowは、企業向け自律AIエージェントの共同開発・展開に向けた協業を発表した。NVIDIAのNIM（NVIDIA Inference Microservices）とServiceNowの業務プラットフォームを統合し、ITサービス管理・HR・カスタマーサポートなど幅広い業務プロセスをエージェントが自律処理する仕組みを構築する。Deloitteの2026年第1四半期調査では生成AIを導入した企業の68%がアジェンティックAIパイロットを実施中と報告されており、エンタープライズAIの主戦場は生成から自律実行へと急速に移行している。ガートナーは2026年末までにエンタープライズアプリの40%がタスク特化型AIエージェントを組み込むと予測しており、今回の協業はその代表的な実装モデルと位置づけられる。

GitHub Copilot、トークン消費量課金制に移行 — 月29ドルが750ドル相当に膨れ上がるケースも

GitHubは開発者向けコーディング支援ツール「GitHub Copilot」の課金モデルをシートベースからトークン消費量ベースに移行し、ヘビーユーザーを中心に大幅なコスト増大への批判が噴出している。一部ユーザーは従来月29ドルだった費用が新モデル下では約750ドル相当になりうると報告しており、SNS上では「ジョークかと思った」「実質25倍の値上げだ」といった声が相次いだ。GitHubはトークン効率の高い利用スタイルへの移行を促す意図があるとしているが、大規模コードベースや複数AI機能を同時活用するユーザーほど影響が大きい構造だ。AIコーディングツール市場の競争激化の中、このビジネスモデル刷新は他ツールへのスイッチングを加速させる可能性があり、業界全体の料金体系議論を促しそうだ。
