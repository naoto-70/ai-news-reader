SoftBank、フランスに最大750億ユーロ（約14兆円）のAIデータセンター建設を発表

GitHub Copilot、6月1日より従量課金制（AIクレジット）に完全移行 — 1クレジット＝0.01ドルでトークン消費を計測

GitHubはすべてのCopilotプランを6月1日から従量課金制に切り替え、「GitHub AIクレジット」（1クレジット＝0.01ドル）でAI使用量を管理する新体系を導入した。プランごとに月次クレジット上限が設定され（Copilot Pro+は月39ドル分、Businessは1ユーザーあたり19ドル分）、入力・出力・キャッシュトークンを含むAPI利用がクレジットに換算される仕組みだ。コード補完とNext Edit Suggestionsは引き続き無制限で提供されるが、それ以外のAI機能はクレジット消費の対象となる。Business・Enterpriseの既存顧客には6〜8月にかけてプロモーション用クレジットが付与されるほか、組織単位でのクレジット共有機能も新設された。

Google、Gemini 3.5 Flash を正式リリース — 前世代Proモデル超えのコーディング性能を低コストで提供

Googleは5月19日のGoogle I/O 2026でGemini 3.5 Flashを発表し、Geminiアプリ・AI Studio・Gemini API・Google Search AIモードで一般提供を開始した。同モデルは前世代のGemini 3.1 Proをコーディングとエージェントタスクで上回る性能を実現しつつ、価格を入力100万トークンあたり1.50ドル・出力9ドルと大幅に抑えた。コンテキストウィンドウは100万トークンで、Terminal-Bench 2.1では76.2%を記録し、同価格帯のモデルの中で最速クラスのレスポンス速度も備える。エンタープライズ向けにはGlobal・US・EU各リージョンでVertex AI経由の正式提供も行われており、Gemini Enterprise契約企業から利用可能だ。

セールスフォース・ジャパン、日本企業のAI活用支援にデータ管理投資を強化 — 「データ分断」解消が鍵と強調

セールスフォース・ジャパンの小出伸一会長兼CEOは、日本企業のAI導入を効果的に支援するため、データ管理分野への投資を強化する方針を明らかにした。同氏は多くの日本企業で部門間のITシステムが断片化しており、AIアプリケーションが必要な情報へアクセスしにくい「データ分断」が普及の最大障壁だと指摘した。Salesforceはデータ統合と管理の強化を優先し、現場でAIが実効性を発揮できる環境整備を後押しする計画だ。国内でのAI活用率向上が急務とされる中、外資系大手によるデータ基盤整備への本格投資は日本のAIビジネス加速に向けた重要な動きとなりそうだ。
