日本政府、370兆円（約2.3兆ドル）長期投資計画を発表——AIと半導体に101.6兆円を重点配分

高市首相が2041年3月末を最終年度とする14年間の長期投資計画（総額370兆円・約2.3兆ドル）を発表し、そのうち101.6兆円をAIと半導体向けに配分することを明らかにした。半導体投資は2040年度までに443兆円、フィジカルAIと垂直型AIへの投資はそれぞれ144兆円・222兆円の経済波及効果を生み出すと試算されている。計画は公的投資と民間投資の組み合わせで実現する方針で、政府がインフレ率が想定内に収まれば全体の約半分を負担する見込みだ。少子高齢化による構造的な労働力不足の解消も目標の一つとして掲げられており、AIによる生産性向上が国策として位置付けられた形となる。

Google、さらに2名の上級AI研究者をAnthropicへ失う見通し——Jonas AdlerとAlexander Pritzelが移籍へ

Bloombergの報道によると、GoogleのGemini AIモデル開発に深く関与してきた上級研究者のJonas AdlerとAlexander Pritzelの2名がAnthropicへ移籍する見通しであることが明らかになった。これは、Transformerの共著者Noam ShazeerがOpenAIへ移籍（6月18日）、AlphaFold主導のノーベル賞受賞者John JumperがAnthropicへ移籍（6月20日）したのに続く、Google DeepMindからの連続的な人材流出となる。Googleは次世代モデル「Gemini 3.5 Pro」の7月リリースを控えており、基幹研究者の相次ぐ離脱がAI開発体制に与える影響が懸念される。わずか1週間で複数の著名AI研究者がGoogleを去るという異例の事態を受け、業界全体での人材争奪戦の熾烈化が改めて浮き彫りになっている。

Model Release 2026-06-23

Claude Fable 5、6月23日より有料化——Pro/Maxプランの無料提供13日間で終了、Usage Credits課金へ移行

Anthropicは6月9日のリリースから13日間、Pro・Max・Team・Enterprise各サブスクリプションユーザーに無料で提供していたClaude Fable 5を、6月23日をもって標準プランの無償枠から除外した。以降の利用にはAPIレートに準じたUsage Creditsが必要となり、入力100万トークンあたり10ドル・出力100万トークンあたり50ドルという課金体系が適用される。これはClaude Opus 4.8の2倍の価格水準であり、Anthropicが一般提供している中で最も高額なモデルとなる。同社は「容量が整い次第、標準サブスクリプション内への再統合を予定しているが、時期は未定」とコメントし、あくまで一時的な措置であると強調している。

OpenAI、GPT-5.5-Cyberの完全版をリリース——CyberGymで85.6%の最高スコア、「Patch the Planet」計画も始動

OpenAIは6月22日、サイバーセキュリティ特化モデルGPT-5.5-Cyberの完全版をDaybreakプログラムの一環として公開し、脆弱性の発見から自動パッチ適用まで一気通貫で処理できる能力を大幅に強化した。セキュリティ評価ベンチマーク「CyberGym」では85.6%を達成し、標準GPT-5.5の81.8%を上回って全単一モデル中の最高スコアを記録している。同時に「Patch the Planet（地球規模のパッチ適用）」イニシアチブを発表し、cURL・Go・Python・Sigstore・pyca/cryptographyなど30以上のオープンソースプロジェクトが参加を表明した。現時点でのアクセスは審査済みのセキュリティ研究者・防衛組織に限定されており、追加モニタリングも実施されている。
