日本のAI問題の本質は「信頼の欠如」——技術ではなくガバナンスが普及の壁

Moonshot AI、Kimi K2.7-Code をオープンウェイト公開——1兆パラメータMoEが Hugging Face に登場

Moonshot AIは6月12日、コーディング特化の大規模言語モデル「Kimi K2.7-Code」をHugging Faceでオープンウェイト公開した。総パラメータ数1兆のMoEアーキテクチャ（アクティブ32B・384エキスパート）を採用し、前バージョン「K2.6」比でKimi Code Bench v2スコアが21.8%向上したと報告している。コンテキストウィンドウは256Kトークンで長時間エージェントによるソフトウェアエンジニアリングタスクを主な用途とし、改定MITライセンスのもとで商用利用も可能だ。Kimi APIでは入力100万トークンあたり0.95ドル・出力4.00ドルの料金設定となっており、高コストな商用モデルに対するコスト効率の高い代替として注目を集めている。
