# AI News Daily

AI技術と決済のニュースを日本語でまとめる静的サイトです。2026年9月20日から、開発・保守は Codex を主なアシスタントとして進めます。作業ルールは [AGENTS.md](AGENTS.md) に記載しています。

## 掲載方針

- **AI技術**: モデル・API・開発ツール・実装・評価・推論性能など、開発や運用に役立つ技術情報を優先します。
- **決済**: CAFIS本体、CAFIS関連サービス・接続先、国内の決済基盤・加盟店接続・端末・認証・不正対策の順に優先します。CAFISとの直接の関係と、周辺分野の話題を区別して紹介します。

1号はAI技術5件と決済5件、合計10件を基本とします（各カテゴリ最大5件）。確認できる新情報が不足するカテゴリは件数を減らし、他カテゴリで穴埋めしません。決済も毎回調査しますが、確認できる新情報がなければ無理に掲載しません。この方針は次回の記事更新から適用します。

## ファイル構成

- `docs/index.html` — 最新号
- `docs/archive/` — 日付別の過去号
- `.github/workflows/deploy.yml` — GitHub Pages への公開

## 表示・公開

ビルドや依存パッケージのインストールは不要です。ローカルでは `docs/index.html` をブラウザーで開いて確認できます。

`main` ブランチに push すると、GitHub Actions が `docs/` を GitHub Pages に公開します。公開結果はリポジトリの Actions で確認してください。

## ニュースの更新

Codex に対象日を指定してニュース更新を依頼します。出典を確認して日本語で要約し、前号の保存、最新号の更新、リンクの確認を行います。具体的な手順は [AGENTS.md](AGENTS.md) を参照してください。

引き継ぎ時点の最新号は **2026年8月2日** です。リポジトリ内にはニュース収集の定期実行設定はなく、GitHub Actions は公開のみを担当します。Codex アプリの定期実行「AIニュース毎朝更新」を設定済みです。毎朝9時（日本時間）に出典確認・記事更新・GitHubへの反映を行い、更新完了・失敗・対応が必要な場合に管理タスクへ通知します。設定はCodexアプリ側で管理しており、GitHub Actionsの定期実行ではありません。以前の環境にある定期実行の有無は未確認です。
